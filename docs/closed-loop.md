# Closed-Loop Analytics

## Objective

The Closed-Loop Analytics module evaluates the performance of
decisions recommended by the Supply Prescript optimization engine.

## Closed-Loop Flow

Input Data
→ Prediction
→ Optimization
→ Recommendation
→ Actual Action
→ Actual Outcome
→ Performance Evaluation
→ Feedback

## What We Measure

After a recommendation is implemented, the system compares
expected results with actual results.

### Key Measurements

- Expected Cost
- Actual Cost
- Expected Delay
- Actual Delay
- Expected Inventory
- Actual Inventory
- Cost Savings
- Cost Variance
- Delay Variance
- Decision Success

## Purpose

The analytics module helps determine whether the recommended
decision actually improved the supply-chain outcome.
